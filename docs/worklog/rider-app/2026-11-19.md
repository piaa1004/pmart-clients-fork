## 네이버 로그인 — flutter_appauth(OIDC 인가 코드 + PKCE)
- 사용자 "로그인용 패키지(flutter_appauth)를 새로 넣어"(2026-11-19 승인). 고객앱과 같은 ^13.0.0.
- NaverIdTokenSource: authorizeAndExchangeCode(clientId, redirect, scopes openid, 네이버 OIDC authorize/token) → idToken. Client Secret 은 앱에 넣지 않음(PKCE). 취소 → null, PlatformException → 연결 실패, Client ID 없음 → 설정 문제.
- 돌아오는 주소 com.pmart.rider://oauth/naver(build.gradle appAuthRedirectScheme com.pmart.rider), 네이버 콘솔이 앱 주소를 안 받으면 빌드 때 NAVER_REDIRECT_URL 로 중계 주소(고객 BR-66 과 같은 방식).
- 실서버 버튼은 그대로 rider-auth 0.2.0(백엔드 #250) 병합 전까지 숨김. 시험 1건 추가, flutter test 158 통과, 목·LAN APK 빌드 성공.
