## 전달 불가 알리기 → 바로 지원센터 대화 (사용자: "알리고 나면 상담원과 채팅도 못 하고, 나가서 같은 내용으로 '연락 안 돼요'를 보내야 채팅이 뜬다 — 구조가 이상")
- 원인: 계약상 전달 불가 등록(`POST …/failures`)은 운영자 확인 대기열(`GET /deliveries?state=FAILURE_REPORTED`)로만 가고, 상담원 대화는 도움요청(`POST …/help-requests`) 한 건에 딸린다. 앱이 둘을 따로 두어 라이더가 같은 내용을 두 번 써야 했다.
- 고침: 전달 불가가 등록되면(FAILURE_REPORTED 확인 뒤) 같은 내용으로 도움요청을 자동으로 보낸다 — 유형은 사유에 맞춰(연락 안 됨·부재·거절 → 고객 연락 안 됨, 주소 → 주소 문제, 파손 → 상품 문제, 사고 → 사고, 기타), 내용 "전달 불가를 알렸어요 · 사유: …", 증빙 사진 photoRef 함께. 접수되면 대화 화면으로 바로 간다(실패 화면 대체). 접수 불명이면 배송 화면으로(지원센터에서 다시).

## 전달 불가를 알린 뒤 고객과 다시 연락돼 전달할 수 있을 때 (사용자 지적)
