# 2026-11-23 rider-app 작업 일지 (PC 5)

## 마이페이지 배달 지역 바꾸기
- 사용자 "마이페이지에서 이사한 사람이나 그 지역 근처에 있는 사람은 배달가능지역을 옮길 수 있어야 하잖아"
- 사용자가 정한 것:
  - 운행을 쉴 때만 바꿀 수 있다.
  - 배달 지역은 한 곳만 둔다.
  - 바꾸면 바로 반영한다.
- 앞서 확인한 것(사용자 물음):
  - 배차 후보는 rider-service `eligible` 로 정한다. 배달 지역(`rider_delivery_area.mfc_id`)에 그 MFC 가 있어야 하고, 운행 중·신규배차 켬·제한 없음이어야 한다.
  - 그 뒤 dispatch 가 위치가 최신이고 MFC 중심 직선 1·2·3km 단계 안인 라이더를 고른다.
  - 그래서 "전라권"이 아니라 라이더가 고른 **지점**의 주문만 온다.
  - LAN 목포 MFC = `MFC-MOKPO-01`(PC1 백엔드 R-39, 주소 "전남 목포시 백년대로 352 (상동 869)"). 앱은 주소 "전남" 으로 전라권에 넣는다. 사용자: "3층"은 넣지 않아도 됨. 폰은 연결하지 않아 실기기 확인 안 함.
- 한 일(`apps/rider_app`):
  - `my/data/profile.dart`
    - `RiderProfileView` 에 `deliveryAreaMfcId`(첫 곳)·`version` 을 더했다.
    - `changeDeliveryArea`(`PATCH /riders/me` `deliveryAreas:[{mfcId}]`, 멱등키·X-Expected-Version)를 더했다.
    - 목에는 `failNextChange`·`loseNextReply` 를 두었다.
  - `my/presentation/area_change.dart`(새 파일)
    - 마이페이지 "배달 지역" 줄을 누르면 가입 때와 같은 권역 → 지점 창(`AreaSheet`, signup_screens 의 `_AreaSheet` 를 공개)이 뜬다. 고른 뒤 "○○(으)로 바꿀까요?" 를 묻는다.
    - 운행 중이거나 진행 배송이 있으면 창을 열지 않고 "운행을 종료한 뒤…" 로 안내한다. 묻는 동안 운행을 시작했으면 다시 막는다.
    - 결과를 모르면(연결 끊김·5xx) `GET /riders/me` 로 맞추고, 그것도 안 되면 "확인하지 못했어요" 를 보인다. 거절(4xx)은 "바꾸지 못했어요"(INVALID_STATE 면 운행 중 안내).
    - 끝나면 profile·duty 를 다시 읽는다.
  - 마이페이지 머리의 지점 이름: 쉬는 중에는 배달 지역(내 정보)을 보인다. 운행 상태의 mfcId 는 예전 운행 지점이라 쓰지 않는다.
  - `DutyController.change`: 운행을 새로 시작할 때는 `mfcId` 를 비워 보낸다(서버가 배달 지역으로 정함). 쉬는 동안 남은 예전 지점을 보내면 지역을 바꾼 뒤 `MFC_NOT_IN_AREAS` 로 거절되기 때문. 운행 중 신규배차만 바꿀 때는 지금 지점 그대로.
- 백엔드 요청: `docs/handoff/rider-app/2026-11-23-backend-delivery-area-change.md`
  - (1) 운행 중 배달 지역 변경을 서버도 409 INVALID_STATE 로 막기
  - (2) 쉬는 동안 남는 operatingMfcId 정리
  - (3) 없는·운영 안 하는 지점 거절 여부
  - `docs/handoff/README.md` 열린 목록은 PC 1 몫.
- 확인: `flutter analyze` 문제 없음, `flutter test` 209개 통과(새 `test/area_change_test.dart` 6개 — 바꾸기·결과 불명 맞추기·거절·운행 중 막기·목 버전 409·운행 시작 mfcId 비움). 실기기·LAN 시험 안 함.
- 이어서: PC 1 이 #391 을 main 에 넣음(597f893a). 라이더 백엔드 회신(rider 0.23.0, 백엔드 PR #361, 아직 배포 전)은 세 가지다.
  - 운행 중이거나 진행 배송이 있으면 409 INVALID_STATE.
  - 지역을 바꾸면 남은 operating_mfc_id 를 새 지역 첫 센터로 맞춤.
  - 없는·운영 안 하는 지점은 422 MFC_NOT_AVAILABLE.
  - "한 곳만"은 서버가 강제하지 않는다. 앱이 하나만 보낸다.
  - 이 회신에 맞춰 앱은 422 MFC_NOT_AVAILABLE 일 때 "이 지점은 지금 고를 수 없어요. 다른 지점을 골라 주세요"를 보인다(시험 1개 더함).

## 지원센터 버튼·배송 상세 시트 다듬기
- 사용자 "지원센터에 보라버튼으로 되어있는 채팅상담이랑 문의남기기 UI 별로야. 개선해" + "상세화면 … 아래로 스크롤 할 때 … 매끄럽지가 않아. 고정도 될려다가 안 되는 것 같은 느낌도 들고 다음으로 넘어갈 때 애니메이션도 그렇고 수정해줘".
- 지원센터(`inquiry_screens.dart`)
  - 가로로 긴 보라 버튼 두 줄 → 흰 카드 두 칸을 나란히 두었다. 각 칸은 연보라 원 안 보라 아이콘, 제목, 설명, 오른쪽 위 화살표로 되어 있다. 보라는 아이콘과 아래 탭에만 쓴다.
  - "문의 남기기" 설명을 한 줄에 맞게 "답변이 오면 알려 드려요"로 줄였다.
  - 캡처(`tool/shots_inbox.dart`)로 확인했다.
- 배송 상세 시트(`delivery_screen.dart`)
  - 끄는 동안 화면 전체(지도 포함)를 다시 그리던 것: 시트 높이에 따른 상태(펼침·올림)를 setState 대신 ValueNotifier 로 알려, 안내 문구와 진행 버튼만 다시 그린다. 지도는 RepaintBoundary 로 따로 둔다.
  - 안쪽 내용 끝에서 늘어나는(stretch) 효과가 시트 끌기와 겹쳐 "고정될 듯 말 듯" 하던 것: 안쪽 스크롤을 ClampingScrollPhysics 로 바꿨다.
  - 다음 단계로 넘어가 기본 내용 높이가 바뀔 때 jumpTo 로 툭 튀던 것: animateTo(260ms, easeOutCubic)로 옮긴다. 펼치기·접기도 같은 움직임이다.
  - 진행 버튼이 툭 나타났다 사라지던 것: 아래에서 미끄러져 올라오고 내려간다(AnimatedSlide). 숨은 동안은 누를 수 없고 화면 읽기에도 잡히지 않는다.
  - 스냅(접힘·반·끝 높이에 붙기)도 넣어 봤다. 그러나 2026-11-17 사용자 요청("끌어 올린 만큼 머문다")과 그 시험에 어긋나 빼고, 끌어 올린 만큼 머무는 동작은 그대로 두었다.
  - 시험 맞춤: 진행 버튼이 이제 숨는 동안에도 화면 밖에 있으므로, `delivery_test` 의 "없음"을 "누를 수 없음"(hitTestable)으로 바꿨다. 시트를 올린 다음 프레임부터 버튼이 올라오므로 한 번 더 기다린다.
- 확인: `flutter analyze` 문제 없음, `flutter test` 210개 통과. 시트의 움직임은 폰에서 보지 못했다(폰 미연결). `tool/screenshots.dart` 는 가입 단계(은행 고르기)에서 원래부터 실패해 상세 화면은 캡처하지 못했다.

## MFC 두 곳(부산진구·목포) 점검과 지점 이름 "바로픽 ○○"
- 사용자 "지금 MFC 하나 더 늘어나면서 에러 생긴 곳은 없는지 확인해봐".
  - 코드를 읽어 확인했다(LAN 로그인 불가로 실제 화면은 보지 않음). 라이더 앱은 지점 ID 를 목에만 박아 두었고, 실서버 경로는 서버 이름·주소·좌표를 그대로 쓴다. 가입·지역 바꾸기는 서버 목록을 주소로 권역에 나눈다.
  - 라이더 백오피스는 RS-7 머리줄 센터 고르기·관제 첫 센터·대시보드 센터 거르기가 여러 센터를 전제로 되어 있다.
  - 오류는 찾지 못했다. 남은 위험: 권역은 주소가 강원·충청·전라가 아니면 모두 경상으로 나눈다(서울·경기 지점이 생기면 틀림). 웹 목 데이터에는 센터가 하나뿐이다.
- 이어서 사용자 "바로픽 부산진구 / 바로픽 목포 이렇게 보이게 해".
  - `storeLabel` 을 "PMart {이름}" → "바로픽 {이름}" 으로 바꿨다.
  - `shortStoreName` 을 더했다(mfc_directory). 앞의 "바로픽"·"PMart" 와 뒤의 "MFC"·"지점" 을 뗀다. 그래서 서버 "목포 MFC" → "바로픽 목포", 앱 지점표 "부산진구지점" → "바로픽 부산진구".
  - 적용한 곳: 홈·마이페이지 지점, 배송·제안 상세 픽업지, 주문정보, 배달 지역 줄·바꾸기 확인 문구, 가입·지역 고르기 창의 지점 칸(칸에는 "부산진구"·"목포"만).
  - 그대로 둔 것: "PMart 지원센터"·"PMart 전달지"(지점 이름이 아님), 서버 이름 자체(center-master), 라이더 백오피스 센터 이름.
- 확인: `flutter analyze` 문제 없음, `flutter test` 211개 통과(새 짧은 이름 시험 1개, 기대 문구 맞춤).
