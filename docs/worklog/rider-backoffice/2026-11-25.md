## 칩·탭 누르는 느낌, 보던 목록으로 없앰, 대시보드 지금 표시, 운영 통계 손보기
- 사용자 "상담 관리 구분 탭 선택할 때 클릭하는 느낌으로 바꾸고, 선택된 거 파란 테두리로 바뀌는데 아래테두리 잘리네"
  - 고른 칩의 아래 1px 가 잘렸다. 원인: 칩 묶음 상자가 overflow-hidden 이고 칩 높이를 따로 계산(높이 − 2px)했다.
  - 고친 것(`sim-look.css`·`sim-list.css`): 상자는 자르지 않고 칩이 상자 높이를 채운다. 손가락 커서, 누르면 살짝 작아지고 눌림색, 키보드 초점선을 넣었다. 125% 배율에서 아래 테두리가 보이는 것을 확인했다.
- 사용자 "화면 안에서 탭 선택할 때도 선택하는 UI가 너무 딱딱해" → 밑줄 탭(`role=tab`)에 손가락 커서, 올리면 옅은 보라 판, 누르면 살짝 들어감, 부드러운 색 전환을 넣었다.
- 사용자 "제목 앞에 이전으로 되돌아가는 버튼이 있으니까 < 보던 목록으로 이거 없애" → `QueueNav` 에서 그 링크와 문구를 뺐다. 이전·n/N·다음은 그대로다(uiAlign 시험은 ‹ 단추로 돌아가게 고침).
- 사용자 "대시보드 평균 걸린 시간 … 칸 아래쪽 파란 줄 이거 뭐야? 에러야?" → 라이더별 배송 시간대 칸의 "지금 시간" 표시다. 머리 칸에 "지금"을 쓰고 범례에 "지금 시간"(7일 보기는 "오늘")을 더했다.
- 사용자 "운영 통계에 전달실패율 아래에 점선 없애줘" → RateBar 링크의 점선 밑줄을 없애고 "›"만 남겼다. 마우스를 올리면 밑줄이 생긴다.
- 사용자 "날짜별 클릭해도 아무데도 안 들어가져" · "센터별비교에도 클릭 안 되네" · "라이더별 성과에 탈퇴한 라이더는 빼야지" · "숫자만 일렬로 띡띡 … 직관적으로 이해하기가 어려워"
  - 날짜별: 배송 목록에 날짜로 거르는 계약이 없어, 날짜 줄을 누르면 그날 센터별을 아래에 펼친다. 다시 누르면 접힌다.
  - 센터별 비교: 줄 어디를 눌러도 "이 센터만 보기"다.
  - 라이더별 성과: 직원 라이더 목록(GET /riders riderIds)은 탈퇴한 라이더를 돌려주지 않는다. 다 읽었는데 없는 ID 는 빼고, 못 읽었으면 아무도 빼지 않는다(`useRiderSummariesState`).
  - 모양: 숫자 8칸을 넷으로 묶었다 — 배송 결과(완료·실패 막대 + "요청·배송·완료·실패" 한 줄), 완료율(크게), 지연율(막대), 걸린 시간("배차 2분 → 배송 18분"). 시안 둘(표+막대 / 카드)을 캡처해 비공개 페이지로 보이고, 사용자가 "1번"(표+막대)을 골랐다. 카드 코드는 지웠다.
- 시험: 상담 관리 새 요청 1, 운영 통계 2(펼치기, 탈퇴 빼기)를 더했다. typecheck·lint 깨끗, 운영 통계 7 통과(그 직전 전체 257 통과).
- 목 서버는 127.0.0.1:5186 로 띄웠다(0.0.0.0 은 권한 확인에서 막힘). 브라우저 탭이 두 번 멈췄는데 원인은 모른다.

## 라이더 관제·배송 관리 — 라이더 시뮬레이터 모양으로
- 사용자 "라이더 시뮬레이션에 배송관제탭이랑 라이더관제탭 보고 바꿀 수 있는 부분은 UI 바꾸라니까 차이가 이렇게 많이 나면 어떡해"
- 시뮬레이터(5181, MOCK)와 목 모드 화면을 나란히 캡처해 비교했다. 비교 페이지(비공개): https://claude.ai/artifact/K42TXMpYwMPmMRYQLEFj8H
- 라이더 관제(`ControlPage.tsx`):
  - 맨 위 "먼저 확인해 주세요" 카드 4장 → 시뮬레이터처럼 한 줄.
    - 이상 없으면 "이상 없음 — 지금 확인할 일이 없어요".
    - 있으면 "확인할 일" + 알약(지연 배송·자동 취소 실패·위치 끊김·없음·신규배차 꺼짐, 0 인 것은 안 보임, 누르면 거르기). 오른쪽에 기준 시각.
  - "진행 단계" 6장 → 숫자 칸 넷(운행 중·배송 중·대기·위치 끊김·없음). 단계별 수는 배송 관리 위에 있고, 줄마다 배송 단계도 그대로다.
  - 목록 거르기: 둥근 알약(`.pm-pill-chips`), 넘치면 두 줄. 이름은 시뮬레이터대로 "대기"를 더하고 "끊김 → 위치 끊김·없음", "시험 → 시뮬 라이더만". 지연·배차 꺼짐은 남겼다.
  - 지도 범례는 지도 위 어두운 알약이다. 오른쪽 칸 안내 글도 시뮬레이터 문장으로 바꿨다.
- 배송 관리(`DeliveryPages.tsx`) 위쪽 줄: 시뮬레이터 배송 관제처럼 한 줄로 바꿨다.
  - 왼쪽: 진행 중 전체("찾는 중 n · 배송 중 m").
  - 가운데: 한 상자 안 단계 흐름(라이더 찾는 중 › 가게로 › 가게 대기 › 고객에게 › 고객 앞). 칸에 올리면 원래 상태 이름이 보인다.
  - 오른쪽: 확인할 것 작은 칸(실패 신고·회수 픽업·실패 확정).
  - 아래 표는 그대로다(지도+목록 한 화면은 구조가 커서 사용자에게 묻는다).
- 시험: uiAlign·controlExtras·sim 시험을 새 이름·모양에 맞췄다. 전체 259 통과, typecheck·lint 깨끗.
