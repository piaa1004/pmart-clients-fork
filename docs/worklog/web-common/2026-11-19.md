
## 직원 웹 공용 부품 web-ui 로(브랜치 web-common/ui-shared-parts)
- 백엔드 백오피스 세션 알림(PC 5 동의) + 사용자 "시작해". 모양 부품을 `web/ui` 로: `listParts.tsx`(SearchPanel·StatStrip·GuideBox·AllDone), `SearchSelect.tsx`, `ProgressSteps.tsx`, `motion.tsx`, `motion.css`·`wing.css`. 백오피스·인사팀의 예전 파일은 공용 다시 내보내기(import 그대로), admin.tsx 는 네 부품을 공용에서 다시 내보냄, index.css 는 덩어리 대신 `@import '../../ui/src/motion.css'`·`wing.css`. 인사팀은 백오피스 판으로 맞춤(useNewIds scope 등).
- 안 옮김(라우터·react-dom·앱 조회): StatCard·StickyTitle·PageChrome·workQueue·recentViews·displayNumber·employeeLabels·SavedViews.
- 확인: typecheck·lint(web-ui·백오피스·인사팀)·build·test(web-ui 6, 백오피스 611, 인사팀 85) 통과, mfc-backoffice typecheck·build 통과. rider-backoffice typecheck 는 `./generated/notification` 없음(gen:api 안 함 — 이번 변경과 무관). 화면 캡처로 겉모습 그대로 확인. 알림 `docs/handoff/all/2026-11-19-notice-web-ui-shared-parts.md`.
